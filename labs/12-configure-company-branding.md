Lab 12: Configure Microsoft Entra Company Branding

Objective

Review the company branding settings in Microsoft Entra ID and explore the available options for customizing the organization’s sign-in page.

Environment

* Platform: Microsoft Entra ID
* Tenant: Northstar Technology
* Portal: Microsoft Entra admin center
* License: Microsoft Entra ID P2 trial

Tasks Performed

1. Opened the Microsoft Entra admin center.
2. Navigated to Entra ID → Company branding.
3. Opened the default company branding configuration.
4. Reviewed the available sign-in page customization options.
5. Reviewed Microsoft’s notice regarding the retirement of custom CSS positioning properties in October 2026.

Branding Configuration Options

The default company branding configuration includes the following options:

* Background image
* Banner logo
* Square logo
* Favicon
* Background color
* Sign-in page text
* Username hint

Microsoft Notice

A notification on the Company branding page states that custom CSS positioning properties will be retired in October 2026. Existing configurations using these properties must be updated before the retirement date.

Key Takeaways

* Company branding settings customize the Microsoft Entra sign-in experience.
* Branding can be configured using organizational logos, background images, colors, and sign-in text.
* Custom CSS positioning properties are scheduled for retirement in October 2026.
